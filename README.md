### 👨‍💻 Tentang saya

Saya membangun web yang **cepat, mudah ditemukan, dan aman**, dari server sampai halaman yang dibaca mesin pencari.
Fokus saya ada di persimpangan tiga hal:

- **Technical SEO**: arsitektur situs, Core Web Vitals, crawlability & indexing, structured data, audit teknis.
- **Web & Infrastruktur**: pengembangan web, hosting, konfigurasi server, deployment, dan performa.
- **Keamanan**: aplikasi dengan enkripsi end-to-end yang berjalan offline, tanpa server pihak ketiga.

Saya juga memakai **AI coding agent** dalam alur kerja harian untuk mempercepat pengembangan
tanpa mengorbankan pengujian dan kualitas kode.

#### 🔐 Brankas
Password manager **offline** lintas platform: macOS, Windows, Linux (termasuk Kali).

- Argon2id + XChaCha20-Poly1305, header terautentikasi
- Generator **2FA (TOTP)** dengan pemindai QR, diuji vektor resmi RFC 6238
- Catatan aman untuk kode backup, impor CSV dari Chrome/Firefox/Safari/Bitwarden
- Tanpa server, tanpa langganan, tanpa ekstensi browser

`Rust` `Tauri` `JavaScript` · 26 tes otomatis

</td>
<td width="50%" valign="top">

#### 🗂️ Dokumen
Brankas **file** terenkripsi yang menyamar sebagai folder biasa di macOS & Windows.

- Kunci acak per file, enkripsi **streaming** per 1 MiB (aman untuk video berukuran GB)
- Nama file ikut dienkripsi; file yang diubah, dipotong, atau ditukar terdeteksi
- Seret & lepas, galeri gambar, salinan sementara yang terhapus otomatis

`Rust` `Tauri` `JavaScript` · 13 tes otomatis
